1. **Expliquez, en quelques phrases, la structure actuelle du projet Git après toutes les opérations (branches, merges, commits).**
    - Vous pouvez illustrer avec `git log --graph`.

Reponse de Anas Megder :

le projet Git se compose de plusieurs branches reliées entre elles par des commits.
Chaque branche représente une ligne de développement indépendante (par exemple la branche  main.
Les opérations de merge ont permis de réunir ces différentes lignes dans une même histoire commune.

Une commande comme git log --graph --oneline --all afficherait un graphe où l’on voit les branches se séparer et se rejoindre lors des fusions.
